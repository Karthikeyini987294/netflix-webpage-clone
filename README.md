# 🎬 Netflix Webpage Clone

A Netflix-inspired webpage designed and developed using **HTML5 and CSS3**.

This project was created to practice frontend web development, webpage structure, CSS styling, layouts, images, and responsive design.

## 📌 Project Overview

This project recreates the look and feel of a Netflix-style streaming platform homepage.

The webpage includes a navigation bar, hero/banner section, trending movies section, movie cards, FAQ section, and footer.

## 🚀 Features

- 🎬 Netflix-inspired homepage design
- 🧭 Navigation bar
- 🌐 Language selection
- 🔐 Sign In button
- 🖼️ Hero/banner section
- 🔥 Trending movies section
- 🎞️ Movie cards
- ❓ Frequently Asked Questions (FAQ) section
- 📱 Responsive webpage layout
- 📞 Footer and useful links
- 🎨 Custom styling using CSS

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- Google Fonts

## 🖥️ Sections Included

### 1. Navigation Bar

The navigation section contains:

- Netflix logo
- Language selection
- Sign In button

### 2. Hero Section

The hero section contains:

- Main heading
- Subscription information
- Call-to-action content
- Background image

### 3. Trending Section

The trending section displays multiple movie cards using images.

Example:

Movie 1 | Movie 2 | Movie 3 | Movie 4 | Movie 5 | Movie 6

### 4. FAQ Section

The FAQ section contains frequently asked questions using HTML `<details>` and `<summary>` elements.

### 5. Footer

The footer contains:

- Contact information
- Footer links
- Additional navigation sections
